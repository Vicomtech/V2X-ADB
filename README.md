# V2X-ADB

The V2X-ADB dataset is a V2X message-based dataset designed for the cooperative detection of abnormal driving behaviours in surrounding vehicles. It comprises more than 860 sequences of ETSI Cooperative Awareness Messages (CAM), generated while a vehicle performed a range of manoeuvres, including sudden acceleration and braking, wide and narrow turns, weaving, swerving, and normal driving. The dataset combines both simulated data and real-world recordings, providing a diverse benchmark for evaluating data-driven approaches under controlled and realistic conditions.
